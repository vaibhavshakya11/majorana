# RENP threshold-polarization paper: submission bundle

This directory contains the publication-ready LaTeX manuscript
*Polarization rank at radiative neutrino-pair thresholds: a Dirac--Majorana
test* by Vaibhav Shakya and Swastik Dash, Jayshree Periwal International
School.

Designated public repository:
<https://github.com/vaibhavshakya11/majorana>

The main paper develops a resolved diagonal-threshold rank theorem for the
two-polarization RENP response, its second-eigenvalue and recoil-dark
observables, the limits of the theorem, a finite experimental validity window,
and a conditional experimental concept.  The appendices contain the full weak
tensor, target-transfer, finite-channel, optical, statistical, numerical, and
rate/background checks.

## Manuscript files

- `renp_yau_publication_ready.pdf` is the final rendered paper.
- `main.tex` is the LaTeX entry point.
- `sections_1_3.tex`, `sections_4_6.tex`, and `sections_7_10.tex` contain the
  main text.
- `appendices_a_d.tex`, `appendices_e_g.tex`, and `appendices_h_i.tex` contain
  the appendices.
- `references.bib` contains the bibliography.

The source uses A4 paper, 2.5 cm margins, one-and-a-half line spacing, the
default LaTeX serif font, black body text, and restrained color only inside
TikZ/PGFPlots figures.  All figures are generated by LaTeX; no proprietary
fonts, templates, or external graphics are needed.

Compile from this directory with:

```sh
tectonic main.tex
```

A conventional LaTeX/BibTeX sequence compatible with `natbib` can also be
used.

## Numerical files

- `renp_numerical_stress.py` is the main assertion-backed tensor and numerical
  audit.
- `renp_core_crosscheck.py` is an independent shorter derivation check.
- `renp_end_to_end_demo.py` is the normalized synthetic detector-chain study.
- `renp_figure7_convolution.js` reproduces the plotted Gaussian-convolution
  coordinates without third-party packages.
- The two JSON and five CSV files are stored outputs used by the numerical
  appendices and detector demonstration.

The Python programs have commented mathematical headers, fixed seeds, and
assertions.  The archived JSON and CSV data come from the earlier numerical
run described in Appendix H.  In accordance with the project instruction, no
Python program was executed during the final editorial pass.  The NuFIT 6.1
PMNS constants and the corresponding summary block in
`renp_numerical_results.json` were synchronized manually and checked
algebraically and structurally with non-Python tools.  This archive is therefore
not described as a fresh end-to-end Python rerun.  To recertify it, run the
supplied programs in a clean environment and compare regenerated outputs;
floating-point last bits may depend on NumPy, SciPy, and BLAS versions.

The JavaScript figure check can be run with:

```sh
node renp_figure7_convolution.js
```

`MANIFEST.sha256` records the frozen release hashes.

create a tag or release identifying the version submitted with the paper.
